# ネイル試着ノート

自分の手の写真に、爪の輪郭を指定して色や柄を合成し、ネイリストとの相談用画像を作る Web アプリのサンプルです。
iPhone / iPad の Safari での利用を想定しています。ビルド不要の静的ファイルだけで動きます。

- 写真は端末内（Canvas 2D）だけで処理し、外部サーバーへは送信しません
- 生成AI・有料API・ログイン・課金は使いません
- 作業は IndexedDB に自動保存し、編集データ（.json）の書き出し／読み込みもできます

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/app.css` | 見た目（iPad横＝左に写真・右にパネル、縦向き／iPhone＝上下） |
| `js/util.js` | 幾何計算（輪郭のスプライン、爪の座標系） |
| `js/store.js` | IndexedDB 保存、画像の縮小・アセット管理 |
| `js/materials.js` | 試着用デザイン（自作6種）、柄、装飾。許可済み素材の追加場所 `LICENSED_MATERIALS` |
| `js/render.js` | 爪ごとの合成、拡大図、相談用シート |
| `js/demo.js` | 図解デモ素材（実写ではありません） |
| `js/app.js` | 状態・履歴・タッチ操作・パネル |
| `tools/build_artifact.py` | 1ファイルにまとめたプレビュー用 HTML を `dist/` に作る |

## データの持ち方

- 座標はすべて「読み込み時に縮小した作業画像（長辺最大2000px）」基準で保存します。表示・書き出しは同じ座標から描くので、拡大縮小や画面回転でずれません。
- 指ごとに `shape`（輪郭点・根元・先端）と `design`（色・柄・変形・フレンチ・ラメ・装飾）を分けて保持します。柄の位置は爪の幅・長さに対する比率なので、輪郭を直しても追従します。
- 元に戻す／やり直すは状態全体のスナップショットで、写真の差し替えも戻せます。

## 公開方法

GitHub Pages などの静的ホスティングに、このリポジトリのファイルをそのまま置けば動きます（`index.html` が入口）。
